## Features

- Audio transcoding via FFmpeg WebAssembly
- Modern, responsive UI
- Keyboard shortcuts
- Accessibility support (WCAG 2.1 AA)

## Tech Stack

- Vue 3
- Tauri 2
- TypeScript
- Pinia
- FFmpeg WebAssembly

## Development

```bash
pnpm install
pnpm tauri dev
```

## Build

```bash
pnpm tauri build
```
