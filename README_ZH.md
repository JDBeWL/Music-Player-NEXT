## 功能特点

- 冷门格式使用FFmpeg WebAssembly音频转码
- 现代响应式界面
- 键盘快捷键
- 无障碍部分支持(WCAG 2.1 AA)

## 技术栈

- Vue 3
- Tauri 2
- TypeScript
- Pinia
- FFmpeg WebAssembly

## 开发

```bash
pnpm install
pnpm tauri dev
```

## 构建

```bash
pnpm tauri build
```
